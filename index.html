Explore published procurement records.

Explore published public procurement records from several countries and see risk signals, all in your browser.

A signal is a reason to look, not proof.

Scan the selected scope’s published collections sequentially. Collections can overlap: results are not unique contracts. Slow and bandwidth-intensive: each page rescans from the beginning, retaining at most 200 matches. Each source keeps its own assessment rules; unknown is not zero. Amount filters use native currencies, without conversion or combined totals.

Page membership follows collection then published record order (Korea: shard / buyer / row). Sort and grouping controls apply within this scan page only; there is no globally sorted result set or cross-country ranking. Changing filters, sorting, page size or review notes requires a fresh scan. Copy and exports contain only this scan page.

    Your browser may block automatic loading of a local file. Open data/decp-history.json with the file picker in the filter panel, or serve this folder with python -m http.server 8000.

        Signals highlight published characteristics for review, not established irregularities.

        The index orders records using the available indicators. “Not assessed” means no applicable check could be evaluated; 0 means no threshold crossed in the evaluated checks. Missing values are shown as unknown.
